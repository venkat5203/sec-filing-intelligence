# LinkedIn launch post

I’ve built a data analytics project using **real public-company filings from SEC EDGAR**.

Introducing **SEC Filing Intelligence & Document Analytics** — a workflow that turns regulatory filings into searchable, structured information for review and analysis.

What it does:

- Starts with a source-verified snapshot of seven real Form 10-K filings from Apple, Amazon, Meta, Microsoft, NVIDIA, FactSet, and Micron.
- Retrieves filing metadata from the SEC submissions API.
- Links each record directly to its original SEC filing.
- Uses Python and BeautifulSoup to extract document text and detect common report sections.
- Calculates word counts, section presence, and selected keyword frequencies.
- Uses SQL queries and interactive dashboards to explore issuer filings and document metadata.
- Includes an optional LLM-assisted synopsis workflow with source-grounded prompts and human verification.

The project uses public SEC filings, not employer or customer data. The static snapshot is a selected sample; live refresh is available in the Python app.
