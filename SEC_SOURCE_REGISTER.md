## Important source notes

- The static site stores filing metadata and direct SEC links; it does **not** store copies of the filing documents.
- Primary-document file sizes and document counts are included only where visible in the corresponding SEC filing index/directory. A blank document count means it was not captured in this snapshot, not zero.
- The Streamlit app and refresh script query the official SEC submissions API for newer 10-K/10-Q metadata. They require a descriptive `SEC_USER_AGENT` containing an app name and contact email.
- Automated requests should be paced conservatively and comply with SEC fair-access requirements.
- Filing data is not a representative sample of all companies, and counts/mentions do not prove misconduct, compliance, risk severity, or investment merit.
